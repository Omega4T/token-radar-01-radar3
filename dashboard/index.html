Model limits — read before trusting any number

  • Data is frozen 14 Nov 2026; nothing newer exists in this radar.
  • Implied value is an estimate from historical market-cap/TVL ratios, not a price prediction.
  • Token odds is a proxy: how similar a protocol looks to protocols that (as far as DefiLlama records) already have a token — not the true probability it launches next year. The snapshot records no launch dates, so no real launch hazard can be estimated.
  • Small categories barely move implied value: shrinkage pulls their multiplier toward 1, and categories with fewer than 3 fit-set members get multiplier exactly 1.
  • Terms that failed selection were dropped and are named in the decision tables above — the model does not claim to use them.
  • “Records no token” is not “has no token”: DefiLlama may simply not record a token that exists.
  • Two things cannot be computed from this snapshot and are never claimed: TVL concentration per chain (only a chain list is given) and revenue, active users or volume (not in the snapshot).

How to read the board

Default order is implied value, highest first. Token odds sits beside implied value in every row — it never changes the order and is never multiplied into it. Use the sort toggle to order by odds instead. Odds bands: Low < 20%, Medium 20–50%, High > 50%. The most informative rows are high implied value with Low odds: worth a lot if it launches, unlikely to launch.
